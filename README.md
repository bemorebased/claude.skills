## What are Skills?

Skills are specialized prompts and instructions that guide AI assistants to perform specific tasks with expert knowledge. Each skill contains:

- **Context** - Domain knowledge and best practices
- **Instructions** - Step-by-step guidance for the task
- **Examples** - Real-world usage scenarios
- **Standards** - Quality criteria and requirements

## What are Agents?

Agents are autonomous assistants designed to handle complex, multi-step workflows. They combine multiple capabilities to:

- Monitor and maintain code quality
- Validate and integrate external data sources
- Analyze and optimize performance
- Review and improve user experience
